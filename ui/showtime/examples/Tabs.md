# Tabs

A frosted segmented pill for top-level sections, and outline chips for filters.

- `.st-tabs`: 3-5 sections; the selected one inverts to `fg`. On phones move these to `.st-tabbar`.
- `.st-chips`: filters that scroll sideways. Pressed chips invert the same way.

Needs: `showtime.css` (or `bundle.css` plus `tokens.css`) and Archivo from Google Fonts.

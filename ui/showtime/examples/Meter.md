# Meter

Bars for ratings and a two-sided scale for verdicts.

- The bar runs from `accent` to `fg`. `.est` marks a value without hard data (dashed, muted).
- `.st-scale` puts a knob on a red-to-green track: trade value, a fair price, a balance.

Needs: `showtime.css` (or `bundle.css` plus `tokens.css`) and Archivo from Google Fonts.

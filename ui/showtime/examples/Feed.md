# Feed

A live timeline: done items, the current one lit, future ones faded.

- `.now` gets the lit row; `.future` fades to half; `.new` slides in from above when added.
- `.st-mark` is a rounded square badge in the item's color: a team, a category, a step.

Needs: `showtime.css` (or `bundle.css` plus `tokens.css`) and Archivo from Google Fonts.

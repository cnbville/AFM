Answer right here. Reply with yes or your change for each one. Question 3 doesn't need an answer now, because the build trial will show you the sizes, each with a why.

1. **Mental health:** each player has a hidden stability level. When it's low, slumps, holdouts, quitting and off-field trouble get more likely. Family, a good coach relationship and team staff lift it. Family events lower it for a while.
2. **Coach reputation:** it catches up with a coach's real ability over about 3 seasons. A big result (a title, a collapse) moves it faster. Assistants' reputations move slower than head coaches'.
4. **NIL warning:** an inbox message from staff, a news story, and a falling arrow on the NIL grade. It repeats as things get worse.
5. **HS NIL data:** a short research pass adds each state's HS NIL rule to the state data, the same way we did transfer rules.
6. **Pipelines:** a pipeline grows each time a signee from that area leads in stats, wins an award or goes in rounds 1-3. It fades slowly after several years with no impact.
7. **Realism defaults** (all real programs, realignment, the coaching carousel): the build thread asks you about these one at a time.
8. **Grade split:** keep it as written.
9. **Escaping to a powerhouse:** yes. It's one of the pulls, and a rare one.

The season calendar and pacing design doc is at /mnt/project-files/design/season-calendar-and-pacing.md (draft v1, 2026-10-10). It defines a 52-week year W1–W52 starting the Monday after the championship game, tension tiers T0–T3, fixed climaxes (draft, cutdown day, trade deadline, playoffs, final) and at most two earned regular-season climaxes.

Defaults it picked, still awaiting Raichel's confirmation: player runs one pro team (HS and college are a simulated, scoutable world); save starts mid-February; real league structure with fictional names.

Decided since: proven breakout seasons can lift a ceiling by up to ~10 points a year at any age, smaller when older (Raichel, 2026-10-10, player model thread); written into section 6 of the doc.

**Why:** Other design threads (development, scouting, contracts) should align their timing to this calendar.
**How to apply:** Reference week numbers from that doc; update this memory if Raichel changes the defaults. Related: [[afm-repo-state]]

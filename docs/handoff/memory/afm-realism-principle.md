Raichel (2026-10-10): "Returning opinion is that everything needs to be realistic." For example, a CB moved to FS keeps value through speed, while an FS with poor run support is worse at SS.

**Why:** Ultra realism is the core of the game, ahead of fun shortcuts.
**How to apply:** When proposing options, recommend the most realistic one and explain it in real football terms. Derive outcomes from underlying attributes rather than flat penalties or fixed numbers. Still ask before deciding ([[raichel-approves-design-decisions]]).

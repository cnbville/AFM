# The line bank: bosses and the outside, on the facts (talk facts lane L10,
# items 13, 15, 16 and 22; format in src/world/folk/voice.rs). Written by hand
# for the most common parts; the bank run (item 12) fills the rest.
#
# Each part is said only when the game has checked the fact it stands on:
# the step a case has reached, where the season stands, who holds the final
# say. A part with no version the speaker can say falls back to the line the
# tree said before (src/world/folk/scene.rs, bank_line; the press asks the
# plain press.q.trouble when there is no part for the step, as for a case
# the league alone handles).

# charge (a DUI, an arrest after a fight), when (today, yesterday, on
# Saturday, last week, on a date), step, again (yes when he has been
# through a case before).
